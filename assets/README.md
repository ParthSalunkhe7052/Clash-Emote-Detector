# 🎨 Assets Folder

This folder contains general project assets including banners, logos, and promotional materials for the Clash Emote Detector.

---

## 📁 Contents

### Branding Assets
- **Project Banner**: `banner.png` - Header image for README (recommended size: 1200x300)
- **Logo**: `logo.png` - Project logo (recommended size: 512x512)
- **Icon**: `icon.ico` - App icon for desktop shortcuts

### Promotional Materials
- Screenshots of key features
- Demo GIFs
- Tutorial images
- Presentation slides

---

## 🎨 Brand Guidelines

**Color Palette:**
- Primary: Purple gradient (#8B5CF6 → #6366F1)
- Secondary: Blue gradient (#3B82F6 → #06B6D4)
- Accent: Pink (#EC4899)
- Background: Dark (#1F2937, #111827)
- Text: White (#FFFFFF), Gray (#9CA3AF)

**Typography:**
- Headings: Bold system fonts
- Body: Regular system fonts
- Code: Monospace fonts

## 🖼️ Image Specifications

| Asset Type | Size | Format | Purpose |
|-----------|------|--------|---------|
| Banner | 1200x300 | PNG | Repository header |
| Logo | 512x512 | PNG | Branding |
| Icon | 256x256 | ICO/PNG | App icon |
| Screenshots | 1920x1080 | PNG/JPG | Documentation |
| GIFs | 800x600 | GIF | Demos |

---

## 📝 Notes

- Keep file sizes optimized for web
- Use PNG for images with transparency
- Use JPG for photographic content
- Use GIF for short animations (< 5 MB)
- Compress images before committing
